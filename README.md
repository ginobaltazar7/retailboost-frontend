## RetailBoost Forecast Demo (Frontend)

A React + Vite [single-page app](https://retailboost-frontend.onrender.com/) that kicks off demand-forecasting jobs and visualizes the results. 

It polls a [companion backend](https://github.com/ginobaltazar7/retailboost-backend/) for async job progress, then renders interactive Chart.js dashboards which are:
- History-vs-projection demand forecast
- Top-genre volume breakdowns
- Plain-language strategy recommendations for Osaka shotengai shops, with one-click PDF deck download.
